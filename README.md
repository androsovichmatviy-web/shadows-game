# Тенепад

Головоломка о свете и тенях в жанре «падающих блоков». Сверху падают осколки света, их нужно укладывать в ряды, поджигать кристаллы и не давать тьме подняться до самого верха.

Игра своя: собственный набор фигур, правила и оформление. Это не копия существующих игр.

## Как запустить

Достаточно открыть `index.html` в браузере. Сборка и зависимости не нужны.

Если браузер не пускает локальные файлы, поднимите простой сервер:

```bash
npm start            # npx serve на http://localhost:8080
# или
python3 -m http.server 8080
```

Игра работает на компьютере (клавиатура) и на телефоне (кнопки под полем и жесты).

## Режимы

**Бесконечный.** Играешь, пока тьма не возьмёт верх. Каждые 10 линий открывают новую глубину: осколки падают быстрее, крупные фигуры выпадают чаще, все очки умножаются на номер глубины. Начиная с глубины 2, снизу поднимается прилив тьмы, и с каждой глубиной всё чаще. Рекорд сохраняется в браузере.

**Уровни.** 12 испытаний с разными целями: собрать линии, зажечь лучи, рассеять все тени, продержаться под приливом, набрать очки. Где-то ограничено число осколков или время. За экономную игру дают до трёх звёзд, каждый пройденный уровень открывает следующий.

| # | Уровень | Цель |
|---|---------|------|
| 1 | Первый свет | собрать 4 линии |
| 2 | Зеркало | собрать 6 линий, научиться отражать фигуры |
| 3 | Осколки света | зажечь 3 луча |
| 4 | Цепная реакция | зажечь 6 лучей |
| 5 | Тени на дне | рассеять все тени |
| 6 | Прилив | продержаться 75 секунд |
| 7 | Шахматная ночь | рассеять ярусы теней |
| 8 | Столпы | срезать три теневых столпа |
| 9 | Спешка | 12 линий за 100 секунд |
| 10 | Пентамания | 6 линий только пятиклеточными фигурами |
| 11 | Глубокая тень | рассеять 6 рядов тьмы за 60 осколков |
| 12 | Затмение | 5000 очков под частым приливом |

## Правила и находки

- **Осколки.** 14 фигур из 2–5 клеток: Пара, Прут, Уголок, Плита, Крюк, Ступень, Звезда, Арка, Вилка, Лестница, Флаг, Угол, Молния и Шпиль. Поле 11 × 18.
- **Отражение.** Кроме поворота, любой осколок можно отразить зеркально.
- **Кристаллы и лучи.** Когда исчезает ряд с кристаллом, кристалл бьёт лучом и выжигает весь свой столбец.
- **Цепная реакция.** Луч, задевший другой кристалл, поджигает его, и тот выжигает свой ряд целиком. Кристаллы в этом ряду продолжают цепочку.
- **Тени.** Тёмные глыбы занимают место в рядах. Их уносят только собранные линии, лучи и Вспышка.
- **Прилив тьмы.** Снизу поднимается ряд теней с одной щелью. Заполни щель, и ряд рассыплется.
- **Сияние и Вспышка.** Линии и лучи заряжают шкалу Сияния. Полная шкала позволяет мгновенно сжечь два нижних ряда.
- **Очки.** Больше рядов за раз, лучи, звенья цепи, рассеянные тени и серии линий подряд дают больше очков.

## Управление

| Клавиши | Действие |
|---------|----------|
| ← → (A D) | двигать |
| ↑ (W, X) | повернуть по часовой |
| Z (Q) | повернуть против часовой |
| C (Shift) | отразить |
| ↓ (S) | ускорить падение |
| Пробел | сбросить вниз |
| F (E) | Вспышка |
| P / Esc | пауза |
| M | звук |

На телефоне: кнопки под полем, касание поля поворачивает фигуру, свайп вбок сдвигает, резкий свайп вниз сбрасывает. Вспышка запускается касанием шкалы «Сияние».

## Устройство проекта

```
index.html        разметка экранов
css/style.css     оформление
js/pieces.js      набор фигур, повороты и отражение
js/levels.js      уровни кампании
js/engine.js      игровая логика без DOM
js/render.js      отрисовка на canvas и эффекты
js/audio.js       звуки, синтезированные через Web Audio
js/main.js        экраны, управление, игровой цикл, сохранения
tests/            тесты логики
```

Тесты запускаются без зависимостей (нужен Node.js 18+):

```bash
npm test
```
