# shadows-game

**Дар Вечности: Эферин** — 3D-прототип экшен-RPG в стиле Genshin Impact на чистом Three.js (без сборщика и зависимостей, кроме вендоренной библиотеки).

Мир и сюжет основаны на прологе «Дар Вечности: Пролог Мира»: континент Эферин, семь стихий, Искры Отклика, Орден Семи Дорог.

## Запуск

Нужен локальный HTTP-сервер (ES-модули не грузятся напрямую с `file://`):

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000/
```

## Механики

- Открытый низкополигональный 3D-мир с камерой от третьего лица (ПКМ + мышь — орбита, колесо — зум).
- Отряд из 5 стихийных странников (Ветер / Гром / Пламя / Иней / Поток), переключение клавишами 1–5.
- Обычная атака, стихийный навык (E) и взрыв стихии (Q, копится по мере ударов).
- Элементальные реакции при комбинировании стихий на враге: Испарение, Плавление, Перегрузка, Наэлектризация, Заморозка, Сверхпроводимость.
- Рывок с полоской выносливости (Shift).
- Архив мира (клавиша C) с лором континента, Ордена и спутников.
- Вступительный диалог-пролог по мотивам исходного текста.

## Структура

- `index.html`, `style.css` — разметка и интерфейс.
- `src/game.js` — вся логика игры (ES-модуль).
- `vendor/three.module.js` — Three.js r160, вендорено локально.
